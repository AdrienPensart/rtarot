# Card images

A modern French tarot deck, *Deck of French Tarot playing cards*, published in
the public domain (CC0) on freesvg.org:
<https://freesvg.org/deck-of-french-tarot-playing-cards>

The PNG renderings come from the `jeuxcartes` LaTeX package by Cédric Pierquet,
which redistributes that deck as `CaJ-TaroTv1-*.png` files:
<https://github.com/cpierquet/latex-packages/tree/main/jeuxcartes>

Files are 250 by 481 pixels, renamed:

- `trump_01.png` … `trump_21.png` and `excuse.png`
- `<suit>_<value>.png` with suit in heart, spade, diamond, club and value from
  01 (ace) to 14 (king), 11 jack, 12 knight, 13 queen
